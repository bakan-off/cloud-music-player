# 🎵 Cloud Music Player

> **Кроссплатформенный музыкальный плеер для Android и Desktop**, воспроизводящий аудио напрямую из открытых папок Google Диска и Яндекс.Диска без подписок, рекламы и авторизации.

## 🌟 Ключевые особенности

- ☁️ **Стриминг из облака без авторизации:** открывает публичные папки Google Диска и Яндекс.Диска любого объема (800+ треков) без токенов, логинов и API-ключей.
- 🔄 **Умная синхронизация:** авто-определение добавленных и удаленных треков из облачной папки в один клик.
- 💾 **Оффлайн-кэширование:** скачивание треков в память устройства для прослушивания в самолете или поездке.
- ⭐ **Система рейтинга (1–5 звезд):** интерактивная оценка треков прямо из плеера или списка с фильтрами по звездам.
- 🗑️ **Быстрая очистка 1★:** моментальное удаление всех нелюбимых треков с 1 звездой и очистка их кэша с устройства.
- 🔀 **Честный Shuffle:** алгоритм перемешивания Фишера — Йетса без повторений.
- 🎧 **Фоновое воспроизведение:** управление со шторки уведомлений, экрана блокировки и Bluetooth-гарнитур.
- 📁 **Импорт локальных треков:** открытие аудиофайлов с телефона или ПК, выставление оценок и сохранение в медиатеку.

## 🚀 Архитектура проекта

```
lib/
├── core/
│   ├── audio/           # just_audio плеер, очередь, честный shuffle, кэширование
│   ├── cloud/           # Парсер открытых папок Google Диска (embedded view) и Яндекс.Диска
│   └── storage/         # SQLite база данных (sqflite / sqflite_common_ffi для Desktop)
├── models/
│   └── track.dart       # Модель трека (метаданные, стрим-ссылка, кэш, рейтинг 1-5)
├── providers/
│   └── library_provider.dart # Управление состоянием (Riverpod, синхронизация с облаком)
├── ui/
│   ├── screens/
│   │   ├── main_navigation_screen.dart # Навигация и плавающий мини-плеер
│   │   ├── library_screen.dart         # Медиатека, фильтры звезд, очистка 1★
│   │   ├── cached_screen.dart          # Оффлайн-хранилище треков
│   │   ├── import_screen.dart          # Подключение облака и синхронизация
│   │   └── player_screen.dart          # Полноэкранный плеер с винилом и рейтингом
│   ├── theme/
│   │   └── app_theme.dart              # Темная тема Obsidian Dark
│   └── widgets/
│       ├── mini_player.dart            # Плавающий компактный мини-плеер
│       └── star_rating_bar.dart        # Интерактивные 5 звезд
└── main.dart
```

## 🛠️ Сборка и запуск

### Требования:
- Flutter 3.20+
- Dart 3.5+
- Android SDK 34+

### Команды:
```bash
# Установка зависимостей
flutter pub get

# Запуск тестов
flutter test

# Запуск на подключенном устройстве / эмуляторе
flutter run

# Сборка установочного APK файла для Android
flutter build apk --debug
# или Release билд:
flutter build apk --release
```

Готовый файл APK появится в `build/app/outputs/flutter-apk/`.
